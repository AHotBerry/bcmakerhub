# BCMaker Hub

BCMaker Hub is a Next.js + Tailwind web portal for a college cosplay and crafting club.

## Folder Structure

```text
app/
  layout.tsx
  page.tsx
  events/page.tsx
  resources/page.tsx
  globals.css
components/
  Navbar.tsx
  BudgetCalculator.jsx
  MemberJoin.jsx
```

## Run locally

```bash
npm install
npm run dev
```
