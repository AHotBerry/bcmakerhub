# ✨ BC Cosplay Club Interactive Web Portal (BC Cosplay Hub)

Welcome to the official digital hub of the **Bellevue College Cosplay Club**! This project is an interactive, community-driven web portal designed to connect anime and gaming fans, prop makers, and costume builders on campus. 

Combining a **soft pastel anime aesthetic** with a **clean minimalist layout**, the portal provides an intuitive platform for members to track events, manage project budgets, and discover resources.

## 🌟 Key Features

*   **🎨 Soft Pastel & Clean Minimalist UI:** Designed with calming lavenders, soft pinks, and crisp white card containers for a modern, distraction-free user experience.
*   **🏠 Home & Scrolling Gallery:** Features an automated, infinite-scrolling gallery showcase highlighting community builds and convention meetups, paired with a quick-glance events preview.
*   **🗓️ Comprehensive Calendar Tab:** Tracks club workshops (wig styling, EVA foam crafting, and convention prep) alongside broader Bellevue College student organization events and volunteer fairs.
*   **🧮 Cosplay Budget Calculator:** An interactive costume cost estimator that allows members to dynamically add project line items (e.g., fabric, Worbla, wigs) and delete them on the fly with real-time total calculations.
*   **👑 Meet the Leadership & FAQ:** Dedicated tabs introducing club officers, outlining core roles, and answering common beginner questions.
*   **💬 Discord Integration:** Direct navigation link to the club's community server (`https://discord.gg/NJJzNEBy84`) for instant member onboarding.

---

## 🛠️ Tech Stack

*   **HTML5:** Semantic document structure and accessibility standards.
*   **CSS3:** Custom properties (CSS variables), responsive Flexbox/Grid layouts, custom animations, and Google Fonts (*Quicksand*).
*   **JavaScript (ES6+):** Client-side interactivity, dynamic DOM manipulation, state handling for the budget calculator, and tab navigation logic.
